# Games You Play Lucra Flows

## Setup and Usage

[Lucra Flows Setup](1.2.7_lucraflows)

## Games You Play Specific Flows

`LucraUiProvider.LucraFlow.CreateGamesMatchup`
Launch the Create Games Landing page. Pass an option `locationId` to pre select the location filter. Otherwise the user can select any location available.

`LucraUiProvider.LucraFlow.CreateGamesMatchupById`
Launch the create games matchup flow with a prepopulate game. This will show a bottom sheet hovering over your experience if launched within a DialogFragment.

`LucraUiProvider.LucraFlow.MatchupDetails`
Launch the matchup details given any matchup ID

`LucraUiProvider.LucraFlow.GamesMatchupDetails` (Deprecated - use MatchupDetails)
Launch the games matchup details flow to show details of a matchup given an ID.
