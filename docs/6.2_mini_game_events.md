# Mini Game Events

[LucraEventListener Setup Guide](1.2.10_lucra_event_listener.md)

## Listening for mini game events

```kotlin
LucraClient().setEventListener(object : LucraEventListener {
    override fun onEvent(event: LucraEvent) {
        when (event) {
            is LucraEvent.MiniGame.Finished -> {
                Log.d(
                    "Sample",
                    "Minigame finished: gameId=${event.gameId} " +
                        "mode=${event.gameMode} amount=${event.amount} matchupId=${event.matchupId}"
                )
                // Refresh user balance, surface rewards sheet, etc.
            }
            else -> Unit
        }
    }
})
```

## Event reference

### `LucraEvent.MiniGame.Finished`

Fired whenever a minigame session ends for the authenticated user, regardless of mode (practice, 1v1, free-for-all, or tournament).

| Field | Type | Notes |
| --- | --- | --- |
| `gameId` | `String?` | Identifier of the game that just finished (e.g. `"runaway-web"`). |
| `gameMode` | `LucraMiniGameMode?` | The mode that the session ran in. Null if the SDK couldn't map the backing value. |
| `amount` | `Double?` | Wager amount in USD. Null for practice / free entry. |
| `matchupId` | `String?` | Associated matchup or tournament ID. Null for practice. |

Use this event to refresh the user's balance, surface earned rewards, or kick the user back to your lobby UI after the session ends.
