# Interacting with Lucra Headless Functionality

After the user logs into the Lucra SDK through the experience, the following headless methods are available to interact with user configuration, Games, Tournaments, Sports Matchups, and more.

Begin interacting with headless functions by obtaining an instance of `LucraClient` via its singleton reference `LucraClient()` or `LucraClient.getInstance()`. Both are functionally equivalent; `getInstance()` may be more convenient for Java consumers.

All headless functions return a sealed class type, enforcing exhaustive `when` statements to ensure all outcomes—including errors—are handled predictably.

> ⚠️ Initialize first: Headless calls will fail if invoked before the SDK finishes initializing. Gate your calls with `waitForLucraClient`:
>
> - Coroutine (Kotlin):
>   ```kotlin
>   CoroutineScope(Dispatchers.Main).launch {
>     val lucraClient = LucraClient.waitForLucraClient()
>     // now safe to make headless calls
>   }
>   ```
> - Callback (Java/Kotlin):
>   ```java
>   LucraClient.waitForLucraClient(
>       () -> {
>         // now safe to make headless calls
>       },
>       throwable -> {
>         // optional failure handling
>       }
>   );
>   ```
>
> See initialization details in [Initialize the LucraClient](1.2_initialize_client.md#interacting-with-the-lucraclient-asynchronously).

## Achievements Related Headless Methods

> **Experimental feature**: `LucraClient.getUserAchievements(...)` is marked `deprecated` to surface a compiler warning at every call site. This does not mean the method is going away; it signals that the feature is experimental. Use with caution and contact [Lucra support](mailto:support@lucrasports.com) if you need assistance.

Use `LucraClient.getUserAchievements(...)` to fetch the current user's achievement progress and drive custom UI.

```kotlin
LucraClient().getUserAchievements(
  viewed = null,
  claimed = null,
  includeNoProgress = false,
) { result ->
  when (result) {
    is AchievementInteractions.GetUserAchievementsResult.Success -> {
      val inProgress = result.achievements.filter { !it.isEarned }
      val completed = result.achievements.filter { it.isEarned }
    }
    is AchievementInteractions.GetUserAchievementsResult.Failure -> {
      when (val error = result.failure) {
        is AchievementInteractions.FailedGetUserAchievements.User -> {
          // NotInitialized or NotAllowed
        }
        is AchievementInteractions.FailedGetUserAchievements.CustomError -> {
          Log.w("Lucra SDK", error.message)
        }
        AchievementInteractions.FailedGetUserAchievements.Unknown -> {
          Log.w("Lucra SDK", "Unknown achievement error")
        }
      }
    }
  }
}
```

**Parameters:**

| Parameter | Type | Description |
|---|---|---|
| `viewed` | `Boolean?` | Filter by viewed status. Pass `null` to include both. |
| `claimed` | `Boolean?` | Filter by claimed status. Pass `null` to include both. |
| `includeNoProgress` | `Boolean` | When `true`, includes achievements the user has not yet started. |

**Response Type:** `AchievementInteractions.GetUserAchievementsResult`

**Errors:**

| Case | Description |
|---|---|
| `FailedGetUserAchievements.User(NotInitialized)` | SDK is not initialized or no user is logged in. |
| `FailedGetUserAchievements.User(NotAllowed)` | Account is blocked, suspended, or otherwise restricted. |
| `FailedGetUserAchievements.CustomError(message)` | Backend returned a specific error message. |
| `FailedGetUserAchievements.Unknown` | Unexpected error without a specific message. |

## User Related Headless Methods

### Observe the Lucra SDK User

**Description:**  
Observe the active `SDKUser` based on authentication status. Useful for determining when the user is logged in.

**Methods:**

- `observeSDKUserFlow()` — coroutine-based
- `observeSDKUser(callback)` — callback-based

**Example:**

```kotlin
private fun observeLoggedInUser() {
  LucraClient().observeSDKUserFlow().onEach { sdkUserResult ->
    when (sdkUserResult) {
      is SDKUserResult.Success -> {
        Log.d("Lucra SDK Sample", "Fetched latest user")
      }
      is SDKUserResult.Error -> {
        Log.e("Lucra SDK Sample", "Unable to determine authed in status ${sdkUserResult.error}")
      }
      SDKUserResult.InvalidUsername -> {
        // Only returned from username update flow
      }
      SDKUserResult.NotLoggedIn -> {}
      SDKUserResult.Loading -> {}
    }
  }.launchIn(lifecycleScope)
}
```

**Response Type:** `SDKUserResult`

### Configure User Properties

**Description:**  
Pushes profile attributes into Lucra for the currently authenticated user. Only different, non-null values on the supplied `SDKUser` are submitted.

If `configure` is invoked before the Lucra session is established, the request is queued and automatically retried after login. Properties such as `birthday`, `accountStatus`, `userId` and `balance` are ignored. Any values sent here are also surfaced inside `LucraFlow.VerifyIdentity`, minimizing what the user must re-enter during KYC.

**Phone number implications**

- Provide `phoneNumber` only when you intend to bind the Lucra account to that value. After the number is verified, the SDK login flow requires the same phone for future authentications.
- Skip the field (or pass `null`) if you prefer Lucra to collect and manage the phone number directly.
- Whatever value you send appears pre-filled in the Verify Identity flow.

**User metadata implications**

- Use `metadata` to pass identifiers and traits from your system. This is a Map of Strings to Strings, an `external_id` entry (example: `"external_id" to clientUserId`) is recommended at minimum to bind your users to Lucra users. Which will help for score submission and other identifying properties from Lucra systems.

**Method:**

- `configure(SDKUser, onResult: (SDKUserResult) -> Unit)`

**Example:**

```kotlin
LucraClient().configure(
  SDKUser(
      username = "lucra_champ23",
      email = "champ@example.com",
      phoneNumber = "+15555551212",
      firstName = "Jamie",
      lastName = "Rivera",
      address = "123 Main Street",
      city = "Austin",
      state = "TX",
      zip = "78701",
      avatarUrl = "https://cdn.example.com/avatars/jamie.png",
      metadata = mapOf(
        "external_id" to "...",
        "store" to "dallas",
      )
  )
) { result ->
  when (result) {
    is SDKUserResult.Success -> {
      Log.d("Lucra SDK Sample", "Profile updated")
    }
    is SDKUserResult.WaitingForLogin -> {
      Log.d("Lucra SDK Sample", "Queued profile update until Lucra login completes")
    }
    SDKUserResult.InvalidUsername -> {
      Log.w("Lucra SDK Sample", "Username failed validation")
    }
    is SDKUserResult.Error -> {
      Log.e("Lucra SDK Sample", "Profile update failed", result.error)
    }
    SDKUserResult.NotLoggedIn -> {
      // configure waits for login, so this state is unlikely
    }
    SDKUserResult.Loading -> {
      // no-op: configure never returns Loading, but maintain exhaustiveness
    }
  }
}
```

**Response Type:** `SDKUserResult`

### Phone Authentication

**Description:**  
Authenticate a user via phone number with SMS verification code, without launching the Lucra login UI. This is a two-step flow:

1. Submit a phone number to receive an SMS verification code
2. Submit the verification code to complete authentication

An optional resend operation is available to re-send the verification code.

**Methods:**

- `submitPhoneNumber(phoneNumber: String, onResult: (SubmitPhoneNumberResult) -> Unit)`
- `submitVerificationCode(code: String, onResult: (SubmitVerificationCodeResult) -> Unit)`
- `resendCode(onResult: (ResendCodeResult) -> Unit)`

**Example:**

```kotlin
// Step 1: Submit phone number
LucraClient().submitPhoneNumber("+15551234567") { result ->
    when (result) {
        is SubmitPhoneNumberResult.Success -> {
            // Phone number accepted, verification code sent via SMS
            // Prompt user for the code
        }
        is SubmitPhoneNumberResult.Failure -> {
            when (result.error) {
                is PhoneAuthError.NotInitialized -> {
                    Log.e("Lucra", "SDK not initialized")
                }
                is PhoneAuthError.InvalidPhoneNumber -> {
                    Log.w("Lucra", "Invalid phone number format")
                }
                is PhoneAuthError.AlreadyLoggedIn -> {
                    Log.w("Lucra", "User is already signed in")
                }
                is PhoneAuthError.NetworkError -> {
                    Log.e("Lucra", "Network error: ${(result.error as PhoneAuthError.NetworkError).message}")
                }
                is PhoneAuthError.Unknown -> {
                    Log.e("Lucra", "An unexpected error occurred")
                }
                else -> {}
            }
        }
    }
}

// Step 2: Submit verification code
LucraClient().submitVerificationCode("123456") { result ->
    when (result) {
        is SubmitVerificationCodeResult.Success -> {
            val user = result.sdkUser
            Log.d("Lucra", "Authenticated as ${user.username}")
        }
        is SubmitVerificationCodeResult.Failure -> {
            when (result.error) {
                is PhoneAuthError.NotInitialized -> {
                    Log.e("Lucra", "SDK not initialized")
                }
                is PhoneAuthError.PhoneNumberNotSubmitted -> {
                    Log.w("Lucra", "Call submitPhoneNumber first")
                }
                is PhoneAuthError.InvalidCode -> {
                    Log.w("Lucra", "Incorrect verification code")
                }
                is PhoneAuthError.AlreadyLoggedIn -> {
                    Log.w("Lucra", "User is already signed in")
                }
                is PhoneAuthError.NetworkError -> {
                    Log.e("Lucra", "Network error: ${(result.error as PhoneAuthError.NetworkError).message}")
                }
                is PhoneAuthError.Unknown -> {
                    Log.e("Lucra", "An unexpected error occurred")
                }
                else -> {}
            }
        }
    }
}

// Optional: Resend the verification code
LucraClient().resendCode { result ->
    when (result) {
        is ResendCodeResult.Success -> {
            Log.d("Lucra", "Verification code re-sent")
        }
        is ResendCodeResult.Failure -> {
            Log.e("Lucra", "Resend failed: ${result.error}")
        }
    }
}
```

**Error Reference:**

| Error | Applicable To | Description |
|---|---|---|
| `PhoneAuthError.NotInitialized` | All three | SDK has not been initialized |
| `PhoneAuthError.InvalidPhoneNumber` | `submitPhoneNumber` | Phone number is not a valid US number |
| `PhoneAuthError.PhoneNumberNotSubmitted` | `submitVerificationCode`, `resendCode` | `submitPhoneNumber` was not called first |
| `PhoneAuthError.InvalidCode` | `submitVerificationCode` | The verification code is incorrect |
| `PhoneAuthError.AlreadyLoggedIn` | All three | User is already authenticated |
| `PhoneAuthError.NetworkError(message)` | All three | A network error occurred |
| `PhoneAuthError.Unknown` | All three | An unexpected error occurred |

**Response Types:**

| Method | Success | Failure |
|---|---|---|
| `submitPhoneNumber` | `SubmitPhoneNumberResult.Success` | `SubmitPhoneNumberResult.Failure(PhoneAuthError)` |
| `submitVerificationCode` | `SubmitVerificationCodeResult.Success(sdkUser: SDKUser)` | `SubmitVerificationCodeResult.Failure(PhoneAuthError)` |
| `resendCode` | `ResendCodeResult.Success` | `ResendCodeResult.Failure(PhoneAuthError)` |

### Submit Demographic Form

**Description:**  
Submit demographic information for the current user. Date-of-birth components are validated client-side; all other validation (email format, minimum age) is performed server-side.

**Method:**

- `submitDemographicForm(dobDay, dobMonth, dobYear, email, zip?, firstName?, lastName?, onResult)`

**Example:**

```kotlin
LucraClient().submitDemographicForm(
    dobDay = 15,
    dobMonth = 6,
    dobYear = 1990,
    email = "user@example.com",
    zip = "78701",
    firstName = "Jamie",
    lastName = "Rivera"
) { result ->
    when (result) {
        is DemographicInteractions.SubmitDemographicFormResult.Success -> {
            Log.d("Lucra SDK", "Demographic form submitted successfully")
        }
        is DemographicInteractions.SubmitDemographicFormResult.Failure -> {
            when (val error = result.error) {
                is DemographicInteractions.DemographicFormError.APIError -> {
                    Log.w("Lucra SDK", "Server rejected input: ${error.message}")
                }
                DemographicInteractions.DemographicFormError.NotInitialized -> {
                    Log.e("Lucra SDK", "SDK not initialized")
                }
                DemographicInteractions.DemographicFormError.NotAllowed -> {
                    Log.e("Lucra SDK", "Account is blocked or suspended")
                }
                DemographicInteractions.DemographicFormError.InvalidDateOfBirth -> {
                    Log.e("Lucra SDK", "Invalid date of birth components")
                }
                DemographicInteractions.DemographicFormError.Unknown -> {
                    Log.e("Lucra SDK", "Unknown error")
                }
            }
        }
    }
}
```

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `dobDay` | `Int` | Yes | Day of birth (1-31) |
| `dobMonth` | `Int` | Yes | Month of birth (1-12) |
| `dobYear` | `Int` | Yes | Year of birth (e.g. 1990) |
| `email` | `String` | Yes | User's email address |
| `zip` | `String?` | No | Zip code |
| `firstName` | `String?` | No | First name |
| `lastName` | `String?` | No | Last name |

**Response Type:** `DemographicInteractions.SubmitDemographicFormResult`

**Errors:**

| Case | Description |
|------|-------------|
| `DemographicFormError.NotInitialized` | SDK has not finished initializing or no user is logged in. |
| `DemographicFormError.NotAllowed` | Account is blocked, suspended, or otherwise restricted. |
| `DemographicFormError.InvalidDateOfBirth` | The provided day/month/year do not form a valid calendar date. |
| `DemographicFormError.APIError(message)` | Server rejected the input (e.g. underage, invalid email). The `message` contains the server's reason. |
| `DemographicFormError.Unknown` | An unexpected error occurred. |
