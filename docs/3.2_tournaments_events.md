# Tournament Events

[LucraEventListener Setup Guide](1.2.10_lucra_event_listener)

## Listening for tournament events

```kotlin
LucraClient().setEventListener(object : LucraEventListener {
    override fun onEvent(event: LucraEvent) {
        when (event) {
            is LucraEvent.Tournament.Joined -> {
                Log.d("Sample", "Tournament joined: ${event.tournamentId}")
                // Perform any post-join work here (refresh lists, push notifications, etc.)
            }
            else -> Unit
        }
    }
})
```

## Event reference

- **`Tournament.Joined`** – Fired whenever the authenticated user successfully joins a tournament. The `tournamentId` field lets you refresh headless data, update tournament feeds, or trigger confirmation messaging.
