# Games (GYP) Headless Functions

The Lucra SDK exposes headless helpers for Games You Play so hosts can create, inspect, accept, and cancel recreational contests without launching Lucra UI. All functions live on `LucraClient` and report back through sealed result types—handle each branch to cover both success and failure paths.

[Headless function setup](1.2.9_headless_interactions)

## Fetch a recreational matchup
### `getMatchup(matchupId, subscribe, onResult)`

Retrieve the current top-level payload for a recreational matchup. Use `getMatchup` when you need the base `LucraMatchup`; use `getMatchupDetails` when you also need participant groups, individual payouts, group scores, or participant ranking scores.

- **Parameters**
  - `matchupId`: Lucra matchup identifier.
  - `subscribe`: (optional, default `false`) When `true`, opens a no-auth subscription and pushes live updates through `onResult` as matchup data changes. When `false`, fires `onResult` once with the current matchup.
  - `onResult`: callback receiving a `GetMatchupResult`.
- **Results**
  - `GetMatchupResult.Success` - supplies `matchup` (`LucraMatchup`), the full top-level Lucra matchup payload.
  - `GetMatchupResult.Failure` - wraps a `GameInteractions.FailedRetrieveMatchup` describing API vs. location errors.
- **Usage (one-shot query)**

```kotlin
LucraClient().getMatchup(matchupId = "c32d...") { result ->
    when (result) {
        is GetMatchupResult.Success -> {
            val matchup = result.matchup
            Log.d("Lucra SDK", "Matchup status: ${matchup.status}")
        }
        is GetMatchupResult.Failure -> {
            Log.w("Lucra SDK", "Failed to load matchup: ${result.failure}")
        }
    }
}
```

- **Usage (subscription - live updates)**

```kotlin
LucraClient().getMatchup(matchupId = "c32d...", subscribe = true) { result ->
    when (result) {
        is GetMatchupResult.Success -> {
            val matchup = result.matchup
            Log.d("Lucra SDK", "Matchup status: ${matchup.status}")
        }
        is GetMatchupResult.Failure -> {
            Log.w("Lucra SDK", "Failed to load matchup: ${result.failure}")
        }
    }
}
```

> Only one matchup subscription may be active at a time. Calling `getMatchup` with `subscribe = true` again automatically cancels the previous matchup subscription before starting a new one.

## Fetch recreational matchup details
### `getMatchupDetails(matchupId, subscribe, onResult)`

Retrieve the current details for a recreational matchup. Use the default one-shot mode for a single snapshot, or `subscribe = true` for live updates.

- **Parameters**
  - `matchupId`: Lucra matchup identifier.
  - `subscribe`: (optional, default `false`) When `true`, opens a no-auth subscription and pushes live updates through `onResult` as matchup data changes. When `false`, fires `onResult` once with the current matchup details.
  - `onResult`: callback receiving a `GetMatchupDetailsResult`.
- **Results**
  - `GetMatchupDetailsResult.Success` - supplies `details` (`LucraMatchupDetails`) with the core matchup, participant groups, individual payouts, group scores, and participant ranking scores.
  - `GetMatchupDetailsResult.Failure` - wraps a `LucraError` (`UserStateError`, `LocationError`, or `APIError`).
- **Usage (one-shot query)**

```kotlin
LucraClient().getMatchupDetails(matchupId = "c32d...") { result ->
    when (result) {
        is GetMatchupDetailsResult.Success -> {
            val details = result.details
            Log.d("Lucra SDK", "Matchup status: ${details.matchup.status}")
            Log.d("Lucra SDK", "Groups: ${details.groups.size}")
        }
        is GetMatchupDetailsResult.Failure -> {
            Log.w("Lucra SDK", "Failed to load matchup: ${result.error}")
        }
    }
}
```

- **Usage (subscription - live updates)**

```kotlin
LucraClient().getMatchupDetails(matchupId = "c32d...", subscribe = true) { result ->
    when (result) {
        is GetMatchupDetailsResult.Success -> {
            val details = result.details
            details.groups.forEach { group ->
                Log.d("Lucra SDK", "Group ${group.name ?: group.id}: ${group.score}")
            }
            details.participantScores.forEach { score ->
                Log.d("Lucra SDK", "Rank ${score.place}: ${score.username} - ${score.score}")
            }
        }
        is GetMatchupDetailsResult.Failure -> {
            Log.w("Lucra SDK", "Failed to load matchup: ${result.error}")
        }
    }
}
```

> Only one matchup details subscription may be active at a time. Calling `getMatchupDetails` with `subscribe = true` again automatically cancels the previous details subscription before starting a new one.

### Response Model - `LucraMatchupDetails`

| Property | Type | Description |
| --- | --- | --- |
| `matchup` | `LucraMatchup` | Core matchup object: status, type, subtype, participants, and game info. |
| `groups` | `List<MatchupGroupDetails>` | Participant groups. Empty groups are included. |
| `participantScores` | `List<MatchupParticipantScore>` | Per-participant ranking scores for automated score-tracking matchups. |

### `MatchupGroupDetails`

| Property | Type | Description |
| --- | --- | --- |
| `id` | `String` | Unique group identifier. |
| `name` | `String?` | Display name of the group. |
| `outcome` | `ParticipantGroupOutcome?` | Group outcome when the matchup is completed. |
| `score` | `Double?` | Aggregate group score for automated score-tracking matchups. |
| `participants` | `List<MatchupParticipantDetails>` | Participants in the group. |

### `MatchupParticipantDetails`

| Property | Type | Description |
| --- | --- | --- |
| `userId` | `String` | Unique user identifier. |
| `username` | `String` | Display name. |
| `avatarUrl` | `String?` | User avatar image URL. |
| `individualPayout` | `Double?` | Payout amount after take rate and team split. |

### `MatchupParticipantScore`

| Property | Type | Description |
| --- | --- | --- |
| `userId` | `String?` | Unique user identifier. |
| `username` | `String?` | Display name. |
| `avatarUrl` | `String?` | User avatar image URL. |
| `place` | `Int?` | Final rank within the matchup. |
| `score` | `Double?` | Score value. |
| `finishedAt` | `String?` | Timestamp when the participant finished their round. |
| `groupId` | `String?` | ID of the group this participant belongs to. |

## Cancel a matchup details subscription
### `cancelMatchupDetailsSubscription()`

Cancel the active headless matchup details subscription started by `getMatchupDetails` with `subscribe = true`. No-op if no subscription is active.

```kotlin
LucraClient().cancelMatchupDetailsSubscription()
```

## Create a recreational matchup
### `createRecreationalGame(gameTypeId, atStake, playStyle, minigameEnabled, onResult)`

Creates a new recreational matchup for the provided game type and wager type.

- **Parameters**
  - `gameTypeId`: e.g. `"CORNHOLE_DOUBLES"`.
  - `atStake`: `RewardType` enum (cash, tenant reward, no reward, etc.).
  - `playStyle`: `PlayStyle` enum (team vs team, head to head, free for all).
  - `minigameEnabled`: (optional, default `false`) When `true`, the SDK uses minigame-specific geo compliance contexts (`FreeMinigames` / `CashMinigames`) instead of the standard `FreeBuyIn` / `CashBuyIn`. Set this to `true` when creating a matchup for a game that has minigames enabled.
  - `onResult`: callback receiving a `CreateGamesMatchupResult`.
- **Results**
  - `CreateGamesMatchupResult.CreateGamesMatchupOutput` — supplies the new matchup id and payload.
  - `CreateGamesMatchupResult.Failure` — wraps API or validation errors.
- **Usage**

```kotlin
LucraClient().createRecreationalGame(
    gameTypeId = "CORNHOLE_DOUBLES",
    atStake = RewardType.CASH_REWARD,
    playStyle = PlayStyle.TEAM_V_TEAM,
    minigameEnabled = false
) { result ->
    when (result) {
        is CreateGamesMatchupResult.CreateGamesMatchupOutput -> {
            Log.d("Lucra SDK", "Created matchup ${result.matchupId}")
        }
        is CreateGamesMatchupResult.Failure -> {
            Log.e("Lucra SDK", "Create failed: ${result.failure}")
        }
    }
}
```

## Accept a versus recreational matchup
### `acceptVersusRecreationalGame(matchupId, teamId, onResult)`

Accepts a versus-style (team v team / head to head) matchup.

- **Parameters**
  - `matchupId`: matchup to join.
  - `teamId`: Lucra team id the user should join.
  - `onResult`: callback receiving an `AcceptRecreationalGameResult`.
- **Results**
  - `AcceptRecreationalGameResult.Success` — join succeeded; payload includes refreshed matchup data.
  - `AcceptRecreationalGameResult.Failure` — contains `LocationError` or `APIError` converted from the underlying `GetMatchupResult`/accept call.
- **Usage**

```kotlin
LucraClient().acceptVersusRecreationalGame(
    matchupId = "c32d...",
    teamId = "team-123"
) { result ->
    when (result) {
        is AcceptRecreationalGameResult.Success -> {
            Log.d("Lucra SDK", "Joined contest! ${result.matchupId}")
        }
        is AcceptRecreationalGameResult.Failure -> {
            Log.w("Lucra SDK", "Unable to join: ${result.failure}")
        }
    }
}
```

> Behind the scenes the SDK first calls `getMatchup` to ensure the contest is valid and to obtain the latest Lucra matchup object required by the acceptance API.

  - `AcceptRecreationalGameResult.Success`

LucraClient().acceptFreeForAllRecreationalGame(matchupId = "ffa-987") { result ->

## Cancel a recreational matchup
### `cancelRecreationalGame(matchupId, onResult)`

Cancels a recreational matchup created by the authenticated user.

- **Parameters**
  - `matchupId`: matchup to cancel.
  - `onResult`: callback receiving a `CancelGamesMatchupResult`.
- **Results**
  - `CancelGamesMatchupResult.Success`
  - `CancelGamesMatchupResult.Failure`
- **Usage**

```kotlin
LucraClient().cancelRecreationalGame(matchupId = "c32d...") { result ->
    when (result) {
        is CancelGamesMatchupResult.Success -> {
            Log.d("Lucra SDK", "Matchup canceled")
        }
        is CancelGamesMatchupResult.Failure -> {
            Log.e("Lucra SDK", "Cancel failed: ${result.failure}")
        }
    }
}
```

### Result type reference

| Result Type                    | Success Payload             | Failure Payload                          |
| ------------------------------ | --------------------------- | ---------------------------------------- |
| `GetMatchupResult`             | `matchup` (`LucraMatchup`)  | `GameInteractions.FailedRetrieveMatchup` |
| `GetMatchupDetailsResult`      | `details` (`LucraMatchupDetails`) | `LucraError`                             |
| `CreateGamesMatchupResult`     | `matchupId`, `lucraMatchup` | `CreateGamesMatchupResult.Failure`       |
| `AcceptRecreationalGameResult` | `matchupId`, `lucraMatchup` | `LocationError` / `APIError`             |
| `CancelGamesMatchupResult`     | `matchupId`                 | `CancelGamesMatchupResult.Failure`       |

Handle each sealed interface exhaustively to ensure you capture both success and error scenarios.
