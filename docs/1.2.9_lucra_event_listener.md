# Lucra Event Listener

`LucraClient().setEventListener(..)`

Sets a event listener so you can react to user specific events that occur with the Lucra SDK. A `LucraEvent` may hold data associated with the event (ex: `LucraEvent.SportsContest.Create` holds a `contestId`).

- **Parameters:**
    - `LucraEventListener`: listener used to receive a `LucraEvent`

- **Example usage:**

```kotlin
LucraClient().setEventListener(object : LucraEventListener {
  override fun onEvent(event: LucraEvent) {
    when (event) {
      // Tournaments events
      is LucraEvent.Tournament.Joined -> {
        Log.d("Sample", "Tournament joined: ${event.tournamentId}")
      }
      is LucraEvent.Tournament.AutoJoinedTournaments -> {
        Log.d("Sample", "Auto-joined tournaments: ${event.tournamentIds}")
      }

      // Games events
      is LucraEvent.GamesContest.Created -> {
        Log.d("Sample", "Games contest created: ${event.contestId}")
      }
      is LucraEvent.GamesContest.Accepted -> {
        Log.d("Sample", "Games contest accepted: ${event.contestId}")
      }
      is LucraEvent.GamesContest.Canceled ->
        Log.d("Sample", "Games contest canceled: ${event.matchupId}")
      is LucraEvent.GamesContest.Started ->
        Log.d("Sample", "Games contest started: ${event.matchupId}")
      
      is LucraEvent.GamesContest.StartedActive ->
        Log.d("Sample", "Active game contest started: ${event.matchupId} match object: ${event.lucraMatchup}")
      
      // Sports events
      is LucraEvent.SportsContest.Created -> {
        Log.d("Sample", "Sports contest created: ${event.contestId}")
      }
      is LucraEvent.SportsContest.Accepted ->
        Log.d("Sample", "Sports contest accepted: ${event.contestId}")

      is LucraEvent.SportsContest.Canceled ->
        Log.d("Sample", "Sports contest canceled: ${event.matchupId}")

      // Mini game events — see [Mini Game Events](6.2_mini_game_events.md)
      is LucraEvent.MiniGame.Finished ->
        Log.d("Sample", "Mini game finished: ${event.gameId} (${event.gameMode})")
    }
  }
})
```

## AutoJoinedTournaments Event

`LucraEvent.Tournament.AutoJoinedTournaments`

Fired after a successful auto-join response, whether triggered automatically on auth or via the manual `autoJoinTournaments` method.

- **Payload:**
    - `tournamentIds: List<String>` — tournament IDs the user was enrolled in during this call

- **When it fires:**
    - After a successful auto-join response (automatic or manual trigger)
    - If the user was already enrolled in all eligible tournaments, the list may be empty — this is not an error

- **When it does NOT fire:**
    - If the call was silently skipped due to a gate condition not being met (e.g., location permission not granted, feature flag disabled, user blocked)
    - If an endpoint error occurs

See [Initializing the LucraClient](1.2.0_initialize_client.md) for details on the `autoJoin` constructor property and the manual trigger method.
