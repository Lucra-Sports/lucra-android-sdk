## Mini Game Specific Flows

### `LucraUiProvider.LucraFlow.MiniGame`

The UI-bundled counterpart to the headless [`startMiniGame`](6.1_mini_games_headless.md#start-a-minigame-session). Opens the SDK loading screen, runs the same orchestration (user validation, funds checks, GeoComply verification, session API call), and renders the minigame WebView for you. Use this when you do not need to own WebView rendering.

- **Parameters**
  - `gameId`: identifier of the game (e.g. `"runaway-web"`, `"hoops-web"`).
  - `gameMode`: a `LucraMiniGameMode` value (`Practice`, `OneVsOne`, `FreeForAll`, `Tournament`).
  - `amount`: (optional) wager amount in USD. Pass `null` for practice / free entry.
  - `matchupId`: (optional) required for `LucraMiniGameMode.Tournament`. Ignored for other modes.
  - `handlePostNavigation`: (optional, defaults to `false`) when `true`, the SDK owns post-session navigation — on session end, for non-practice / non-tournament modes that produced a `matchupId`, it navigates to the [`MinigameMatchupDetails`](#lucrauiproviderlucraflowminigamematchupdetails) screen instead of dismissing. Leave this `false` if you want to own post-session navigation yourself.

- **Usage**

```kotlin
val lucraFlow = LucraUiProvider.LucraFlow.MiniGame(
    gameId = "runaway-web",
    gameMode = LucraMiniGameMode.Practice,
    amount = null,
    matchupId = null,
    handlePostNavigation = false,
)

LucraClient()
    .getLucraDialogFragment(lucraFlow)
    .show(supportFragmentManager, lucraFlow.toString())
```

When the user finishes the session, the SDK emits [`LucraEvent.MiniGame.Finished`](6.2_mini_game_events.md#lucraeventminigamefinished) through your registered `LucraEventListener`. If `handlePostNavigation` is `true` and the mode/result qualifies, the flow navigates to the matchup details screen instead of dismissing; otherwise the flow dismisses and it's up to you to decide where to navigate next.

### `LucraUiProvider.LucraFlow.MinigamesHome`

The minigames-flavored landing screen, with a profile pill, an achievement card, a perpetual game carousel and a featured tournament card. Playing a game routes into Game Mode Selection (the mode / wager / battle-tier picker) before launching the minigame; the profile, rewards and tournament touchpoints route to their respective minigames flows.

- **Usage**

```kotlin
val lucraFlow = LucraUiProvider.LucraFlow.MinigamesHome

LucraClient()
    .getLucraDialogFragment(lucraFlow)
    .show(supportFragmentManager, lucraFlow.toString())
```

### `LucraUiProvider.LucraFlow.MinigamesProfile`

The minigames-flavored profile screen, showing the user's avatar, username, balance, competition stats and recent game and tournament results.

- **Usage**

```kotlin
val lucraFlow = LucraUiProvider.LucraFlow.MinigamesProfile

LucraClient()
    .getLucraDialogFragment(lucraFlow)
    .show(supportFragmentManager, lucraFlow.toString())
```

### `LucraUiProvider.LucraFlow.MinigamesRewards`

The minigames-flavored achievement rewards screen. It groups achievement progress and unclaimed rewards by game, shows the achievement closest to completion when a game section is collapsed, and lets users expand a section to view the remaining achievements.

Earned, unclaimed achievement rewards open the SDK redemption sheet. Claiming a reward marks the achievement as claimed, opens its claim URL when one is available, and refreshes the list. Users can also open a per-game history of claimed rewards. In-progress achievements are displayed for progress tracking but cannot be redeemed.

- **Usage**

```kotlin
val lucraFlow = LucraUiProvider.LucraFlow.MinigamesRewards

LucraClient()
    .getLucraDialogFragment(lucraFlow)
    .show(supportFragmentManager, lucraFlow.toString())
```

### `LucraUiProvider.LucraFlow.MinigameMatchupDetails`

The minigames-themed result screen. Prefer launching [`MatchupDetails`](1.2.7_lucraflows.md) from outside the minigames flow, the agnostic router automatically routes to this destination when appropriate.

- **Parameters**
  - `matchupId`: identifier of the matchup to display.

- **Usage**

```kotlin
val lucraFlow = LucraUiProvider.LucraFlow.MinigameMatchupDetails(
    matchupId = "matchup-id",
)

LucraClient()
    .getLucraDialogFragment(lucraFlow)
    .show(supportFragmentManager, lucraFlow.toString())
```
