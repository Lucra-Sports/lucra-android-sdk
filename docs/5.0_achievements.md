# Achievements (Android)

Achievements are milestone-based awards that users earn by completing specific in-game or in-tournament actions: hitting a score threshold, winning a certain number of matchups, placing in a tournament, or simply participating. When an achievement is earned, the SDK can surface a reward sheet that lets users claim any associated prizes.

**Requires `:sdk-ui`** for the built-in Achievements screen and reward sheet flows.

---

## How Achievements Work

1. A user earns an achievement by meeting its criteria (set on the backend).
2. The achievement appears in the Achievements list with an **earned** state.
3. The user claims the achievement reward via the Achievements UI or a custom flow you build using the headless API.
4. Once claimed, `claimedAt` is set on the `LucraAchievement` record.

---

## Entry Point - Full-Screen Achievements List

Use `LucraUiProvider.LucraFlow.Achievements` to open the SDK's built-in full-screen view. It displays two sections: **In Progress** and **Completed**.

```kotlin
val lucraFlow = LucraUiProvider.LucraFlow.Achievements

LucraClient()
    .getLucraDialogFragment(lucraFlow)
    .show(supportFragmentManager, lucraFlow.toString())
```

See [Lucra Flows](1.2.7_lucraflows.md) for full presentation details, including embedded fragments and Compose entry points.

---

## Reward Sheet

When you want to surface earned rewards without navigating away from your current screen, use the achievement rewards sheet flow. This presents a dismissible bottom sheet listing the claimable rewards attached to the provided achievements.

```kotlin
fun showRewardSheet(achievements: List<LucraAchievement>) {
    val lucraFlow = LucraUiProvider.LucraFlow.ClaimAchievementRewards(
        achievements = achievements
    )

    LucraClient()
        .getLucraDialogFragment(lucraFlow)
        .show(supportFragmentManager, lucraFlow.toString())
}
```

Achievements without an attached catalog reward are ignored by this sheet flow. `ClaimAchievementRewards` is seeded from the achievements you provide, so fetch achievements first and pass the claimable items into the flow. The unseeded reward sheet path can fetch combined rewards automatically, but this achievement-specific flow does not.

## Headless API

> **Experimental feature**: This method is marked `deprecated` to surface a compiler warning at every call site. This does not mean the method is going away; it signals that the feature is experimental. Use with caution and contact [Lucra support](mailto:support@lucrasports.com) if you need assistance.

Use `LucraClient.getUserAchievements` to fetch achievements programmatically and drive custom UI.

```kotlin
@Deprecated(
    message = "This is an experimental feature. Use with caution and contact Lucra support if you need assistance.",
    level = DeprecationLevel.WARNING,
)
fun getUserAchievements(
    viewed: Boolean? = null,
    claimed: Boolean? = null,
    includeNoProgress: Boolean = true,
    onResult: (AchievementInteractions.GetUserAchievementsResult) -> Unit,
)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `viewed` | `Boolean?` | Filter by viewed status. `null` returns both viewed and unviewed. |
| `claimed` | `Boolean?` | Filter by claimed status. `null` returns both claimed and unclaimed. |
| `includeNoProgress` | `Boolean` | When `true`, includes achievement definitions even when the user has no recorded progress. |

### Example

```kotlin
LucraClient().getUserAchievements(
    viewed = null,
    claimed = null,
    includeNoProgress = false,
) { result ->
    when (result) {
        is AchievementInteractions.GetUserAchievementsResult.Success -> {
            val inProgress = result.achievements.filter { !it.isEarned }
            val completed = result.achievements.filter { it.isEarned }
            // Update your UI with inProgress and completed.
        }

        is AchievementInteractions.GetUserAchievementsResult.Failure -> {
            when (val error = result.failure) {
                is AchievementInteractions.FailedGetUserAchievements.User -> {
                    when (error.error) {
                        AchievementInteractions.FailedGetUserAchievements.UserStateError.NotInitialized -> {
                            // Route to login or wait for SDK initialization.
                        }
                        AchievementInteractions.FailedGetUserAchievements.UserStateError.NotAllowed -> {
                            // Show an account status error.
                        }
                    }
                }
                is AchievementInteractions.FailedGetUserAchievements.CustomError -> {
                    Log.w("Lucra SDK", "Failed to load achievements: ${error.message}")
                }
                AchievementInteractions.FailedGetUserAchievements.Unknown -> {
                    Log.w("Lucra SDK", "Unknown achievement error")
                }
            }
        }
    }
}
```

### Error Type - `FailedGetUserAchievements`

| Case | Description | Recommended action |
|---|---|---|
| `User(NotInitialized)` | SDK initialization has not completed or no user is logged in | Wait for initialization or route to login |
| `User(NotAllowed)` | Account is blocked, suspended, or otherwise restricted | Show an account status error |
| `CustomError(message)` | Backend returned a specific error | Display the message or retry |
| `Unknown` | Unexpected error without a specific message | Show a generic error |

## Data Models

### `LucraAchievement`

Represents a user's record for a single achievement.

```kotlin
data class LucraAchievement(
    val id: String,
    val achievementId: String,
    val userId: String,
    val tenantId: String,
    val matchupId: String?,
    val userGameScoreId: String?,
    val isEarned: Boolean,
    val earnedAt: Date?,
    val viewedAt: Date?,
    val claimedAt: Date?,
    val achievement: LucraAchievementDefinition?,
)
```

| Property | Description |
|---|---|
| `isEarned` | `true` when the user has met the achievement criteria. |
| `earnedAt` | Timestamp when the achievement was earned. |
| `viewedAt` | Timestamp when the user first viewed the achievement. |
| `claimedAt` | Timestamp when the reward was claimed; `null` if unclaimed. |
| `achievement` | Nested definition describing the achievement title, icon, criteria, and reward. |

### `LucraAchievementDefinition`

The definition of an achievement as configured on the backend.

```kotlin
data class LucraAchievementDefinition(
    val id: String,
    val title: String,
    val description: String?,
    val iconUrl: String?,
    val criteriaType: LucraAchievementCriteriaType,
    val criteriaConfig: LucraAchievementCriteriaConfig,
    val gameId: String?,
    val catalogReward: LucraCatalogReward?,
)
```

### `LucraAchievementCriteriaType`

Describes what the user must do to earn the achievement.

```kotlin
enum class LucraAchievementCriteriaType {
    SCORE_THRESHOLD,
    WIN_COUNT,
    PLACEMENT_COUNT,
    PARTICIPATION_COUNT,
}
```

| Case | Earned when... |
|---|---|
| `SCORE_THRESHOLD` | User's score meets the threshold and operator condition. |
| `WIN_COUNT` | User wins a specified number of matchups. |
| `PLACEMENT_COUNT` | User finishes within a specified rank a given number of times. |
| `PARTICIPATION_COUNT` | User participates in a specified number of matchups. |

### `LucraAchievementCriteriaConfig`

Flat data class that carries the numeric parameters for any criteria type.

```kotlin
data class LucraAchievementCriteriaConfig(
    val threshold: Double?,
    val conditionOperator: ConditionOperator?,
    val count: Int?,
    val place: Int?,
) {
    enum class ConditionOperator { GTE, LTE, EQ }
}
```

## Common Patterns

### Show the reward sheet after loading unclaimed achievements

```kotlin
LucraClient().getUserAchievements(
    viewed = true,
    claimed = false,
    includeNoProgress = false,
) { result ->
    if (result is AchievementInteractions.GetUserAchievementsResult.Success) {
        val unclaimed = result.achievements.filter {
            it.isEarned && it.claimedAt == null
        }

        if (unclaimed.isNotEmpty()) {
            val lucraFlow = LucraUiProvider.LucraFlow.ClaimAchievementRewards(unclaimed)
            LucraClient()
                .getLucraDialogFragment(lucraFlow)
                .show(supportFragmentManager, lucraFlow.toString())
        }
    }
}
```

### Open full-screen achievements from a custom button

```kotlin
button.setOnClickListener {
    val lucraFlow = LucraUiProvider.LucraFlow.Achievements
    LucraClient()
        .getLucraDialogFragment(lucraFlow)
        .show(supportFragmentManager, lucraFlow.toString())
}
```
